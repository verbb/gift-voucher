Gift Voucher adds flexible, trackable digital vouchers to Craft Commerce. Sell fixed or customer-selected values, deliver branded PDFs, and let recipients use every remaining part of their balance.

Each voucher is a native Craft Commerce purchasable, fitting the store’s existing cart, checkout, order, tax and shipping workflows.

## Features

- **Voucher types:** Group vouchers into reusable product types with their own fields and presentation.
- **Flexible amounts:** Offer fixed values or let customers choose how much to give.
- **Partial redemption:** Apply only what an eligible order needs and retain the remaining balance.
- **Redemption history:** See the related order, amount and date every time a code is used.
- **Multiple vouchers:** Let more than one voucher contribute to an order, alongside Commerce coupons where applicable.
- **Optional expiry:** Set expiry rules globally or adjust them for an individual code.
- **Manual codes:** Create voucher codes in the control panel for customer service or special occasions.
- **Bulk code generation:** Create a batch of codes for a selected voucher type and site.
- **Staff adjustments:** Update balances, expiry dates and redemption state when support work calls for it.
- **Branded PDFs:** Generate downloadable vouchers from project-owned Twig templates.
- **Email attachments:** Automatically attach voucher PDFs to nominated Craft Commerce emails.
- **Shipping categories:** Treat digital vouchers appropriately when a cart also contains physical products.
